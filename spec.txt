# Project: iac-monitoring-agent

## Goal

Build a lightweight Infrastructure as Code (IaC) project that provisions and configures a monitoring agent on Linux servers.

The system should simulate a real-world DevOps / SRE workflow, including:
- Infrastructure provisioning (Terraform)
- Configuration management (Ansible)
- Monitoring agent (Python)
- systemd service integration

---

## Requirements

### 1. Monitoring Agent (Python)

Implement a Python-based monitoring agent with the following features:

#### Resource Monitoring
- CPU utilization
- Memory usage
- Zombie process count

#### Network Diagnostics
- DNS resolution check for:
  - www.graid.com
- TCP connectivity check for:
  - Internal: 192.168.1.254
  - External: google.com (or similar)

#### Failure Classification
Must distinguish:
- DNS resolution error
- TCP connection timeout
- Connection refused
- Generic socket error

#### Logging
- Use Python logging module
- Output to: /var/log/monitor-agent.log
- Structured logs (timestamp + level)

---

### 2. Infrastructure as Code (Terraform)

Create Terraform configuration to:

- Provision 1–2 Linux virtual machines (VMware or local provider is acceptable)
- Configure basic network settings
- Output VM IP addresses

---

### 3. Configuration Management (Ansible)

Create Ansible playbook to:

- Install Python dependencies
- Deploy monitoring agent
- Configure systemd service
- Ensure agent runs automatically

---

### 4. systemd Service

Create a service file:

- Starts agent on boot
- Restart on failure
- Runs as root (or configurable)
